Esta aplicación web, desarrollada con Python y Streamlit, permite agilizar el razonamiento clínico mediante la vinculación de diagnósticos NANDA, criterios de resultado NOC e intervenciones NIC. Diseñada para profesionales y estudiantes de enfermería que buscan optimizar la planificación de cuidados.
Nota: 

Esta herramienta es de carácter educativo/simulación. Las decisiones clínicas finales deben ser validadas siempre por un profesional colegiado.
